# Intalyzer-phasar

This is the Phasar based implementation of Intalyzer.


## Features

- Detects interrupt service routines (ISRs) in Arduino code
- Identifies shared variables accessed by ISRs and the main program
- Infers potential race conditions between interrupts

## Installation

The project is known to work on ubuntu.

First, install and build Phasar based on instructions on [phasar.org](https://phasar.org/) or [Phasar GitHub repo](https://github.com/secure-software-engineering/phasar).

Then, replace the `CMakeLists.txt` file in `phasar/tools` with [CMakeLists.txt](CMakeLists.txt) and copy the [intalyzer](intalyzer) folder into the same directory `phasar/tools`.

## building and compiling

Go to Phasar's build directory `phasar/build` and run the following commands:

```bash
# Reconfigure the project
cmake ..

# compile the project
make
```

If you have done the previous step at least once, you only need to run the `make` command from the `phasar/build` directory to recompile the project.

## Usage

# Converting to LLVM files

To start analysing the code we first need to convert the dataset into LLVM IR. 

First install the `ino2cpp` converter tool from [The ino2cpp Github repo](https://github.com/arquicanedo/ino2cpp).

Then run the [convert_ino_to_ll.sh](convert_ino_to_sh) bash file in the directory where you want the `.ll` files to end up, with the following format:

```bash
./convert_ino_to_ll.sh <Input directory with .ino files> <Output directory for .cpp/.ll files> <Auto-generated dummy headers directory> <Path to your ino2cpp converter>
```

# run the analysis

To analyse all the LLVM IR files we have just generated, in the `phasar/tools/intalyzer` directory run the following command:

```bash
# run the analysis on all .ll files
./runall.sh <Input directory with .ll files>
# process the results
./process_output.sh
```

This will generate the files `combined_output.txt`, containing the detailed results of the analysis per file, and `final_output.txt`, containing the amount of race conditions found per file and the total amount found.

# run the analysis on a single file

If its a `.ino` file. run the following command in the `phasar/tools/intalyzer` directory:

```bash
# convert it to a .cpp file
python3 <Path to your ino2cpp converter> <the .ino file>
# convert to a .ll file
clang++ -emit-llvm -S <the generated .cpp file>
# run the analysis on the .cpp file
../../build/tools/intalyzer/intalyzer <the .ll file>
```

If its a `.cpp` file. Edit the `intalyzer.cpp` code to include `"main"` as an entry point to the analysis. Then run the following command in the `phasar/tools/intalyzer` directory:

```bash
# convert to a .ll file
clang++ -emit-llvm -S <the .cpp file>
# run the analysis on the .cpp file
../../build/tools/intalyzer/intalyzer <the .ll file>

Both of the methods will generate a file `output.txt` containing the results of the analysis.
